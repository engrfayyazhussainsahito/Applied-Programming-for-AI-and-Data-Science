4. Core Concepts & CPython Systems Internals

5.1 CPython Compact Dictionary & Open Addressing Hash Tables

Prior to Python 3.6, dictionaries stored a sparse array of 24-byte hash table entries, wasting up to $60\%$ of memory space in empty hash buckets. Modern CPython implements the Compact Dict Architecture (designed by Raymond Hettinger and Inada Naoki):

# Compact Dictionary Memory Layout:
indices:  [ -1,  0, -1,  1, -1, -1,  2, -1 ]  # Compact 1-byte integer hash bucket index table
entries:  [
    {"hash": 0x12a4, "key": "name", "value": "Alice"},
    {"hash": 0x89b1, "key": "role", "value": "Admin"},
    {"hash": 0x4f2c, "key": "dept", "value": "Eng"}
] # Dense contiguous array storing entries in exact insertion order

Collision resolution is performed via Perturbation Probing:

$$i = (5 \times i + 1 + \text{perturb}) \pmod{\text{size}}$$

Where perturb starts as the object's 64-bit hash code and shifts right by 5 bits on each probe iteration (perturb >>= 5). This guarantees high entropy distribution across bucket indices and eliminates clustering.

6.1 The Object Model, Metaclasses & C3 Linearization MRO

Classes in Python are first-class runtime objects instances of type (PyTypeObject). When a class is defined, Python coordinates object construction through two distinct dunder methods:

  1. __new__(cls, *args, **kwargs): Static constructor method responsible for physical memory allocation and returning the raw PyObject instance.
  2. __init__(self, *args, **kwargs): Instance initializer that configures attributes on the instantiated object.

In multiple inheritance hierarchies, attribute and method resolution is resolved via C3 Linearization (MRO), satisfying three formal mathematical properties: local precedence order, monotonic inheritance, and consistency with the extended precedence graph.

7. Mathematical & Asymptotic Foundations

C3 Linearization Merge Formula for Method Resolution Order:

Let $C$ be a class inheriting from parent base classes $B_1, B_2, \dots, B_n$. The linear MRO list $L(C)$ is defined recursively as:

$$L(C) = [C] + \text{merge}(L(B_1), L(B_2), \dots, L(B_n), [B_1, B_2, \dots, B_n])$$

The merge function selects the first head element $H$ that does not appear in the tail of any other remaining list in the merge sequence, removes $H$ from all lists, and appends it to the output until all lists are exhausted.

9. Production-Grade Python Implementations

#!/usr/bin/env python3
"""
High-Performance Object-Oriented Polymorphic Domain Model:
Demonstrates __slots__, Abstract Base Classes, and MRO resolution.
"""
import abc
import math
from typing import List

class Shape(abc.ABC):
    """Abstract Base Class enforcing polymorphic geometric contracts."""
    
    @abc.abstractmethod
    def area(self) -> float:
        """Compute mathematical surface area."""
        pass

    @abc.abstractmethod
    def perimeter(self) -> float:
        """Compute geometric perimeter boundary length."""
        pass

    def __repr__(self) -> str:
        return f"<{self.__class__.__name__} Area={self.area():.2f} Perim={self.perimeter():.2f}>"

class Circle(Shape):
    __slots__ = ('_radius',) # Eliminates __dict__ overhead, saving 64% RAM per instance

    def __init__(self, radius: float):
        if radius <= 0:
            raise ValueError("Radius must be positive.")
        self._radius = radius

    def area(self) -> float:
        return math.pi * (self._radius ** 2)

    def perimeter(self) -> float:
        return 2.0 * math.pi * self._radius

class Rectangle(Shape):
    __slots__ = ('_width', '_height')

    def __init__(self, width: float, height: float):
        if width <= 0 or height <= 0:
            raise ValueError("Dimensions must be positive.")
        self._width = width
        self._height = height

    def area(self) -> float:
        return self._width * self._height

    def perimeter(self) -> float:
        return 2.0 * (self._width + self._height)

if __name__ == "__main__":
    shapes: List[Shape] = [
        Circle(radius=5.0),
        Rectangle(width=4.0, height=7.0),
        Circle(radius=2.5)
    ]
    print("--- Polymorphic Shape Evaluation ---")
    total_area = sum(s.area() for s in shapes)
    for s in shapes:
        print(f"  {s}")
    print(f"
Total Surface Area: {total_area:.2f} sq units")

14. Common Misconceptions & Anti-Patterns

  • Misconception: Python passes arguments by value or by reference.
    Reality: Python uses Pass-by-Object-Reference (or Call-by-Sharing). The function receives a reference to the bound object, but reassigning the local parameter name does not rebind the caller's variable.
  • Misconception: The GIL makes multi-threaded Python programs thread-safe.
    Reality: The GIL only protects CPython internal struct invariants. User-level operations across multiple bytecode instructions still require explicit mutex locks (threading.Lock) to prevent race conditions.

from dataclasses import dataclass
from datetime import datetime
from typing import List, Optional

class InsufficientFundsError(Exception):
    pass

@dataclass(frozen=True)
class TransactionRecord:
    timestamp: datetime
    tx_type: str
    amount: float
    resulting_balance: float

class BankAccount:
    def __init__(self, account_id: str, owner: str, initial_deposit: float = 0.0):
        if initial_deposit < 0:
            raise ValueError("Initial deposit cannot be negative.")
        self.account_id = account_id
        self.owner = owner
        self._balance = initial_deposit
        self._ledger: List[TransactionRecord] = []
        
        if initial_deposit > 0:
            self._ledger.append(TransactionRecord(datetime.now(), "DEPOSIT", initial_deposit, self._balance))

    @property
    def balance(self) -> float:
        return self._balance

    def deposit(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("Deposit amount must be strictly positive.")
        self._balance += amount
        self._ledger.append(TransactionRecord(datetime.now(), "DEPOSIT", amount, self._balance))

    def withdraw(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("Withdrawal amount must be strictly positive.")
        if amount > self._balance:
            raise InsufficientFundsError(f"Cannot withdraw ${{amount:.2f}}. Current balance: ${{self._balance:.2f}}")
        self._balance -= amount
        self._ledger.append(TransactionRecord(datetime.now(), "WITHDRAWAL", amount, self._balance))

    def get_statement(self) -> List[TransactionRecord]:
        return list(self._ledger) # Return defensive copy

    def __repr__(self) -> str:
        return f""
