Python & Computer Science Terminology Glossary

Searchable dictionary of fundamental CPython, algorithms, concurrency, and OOP systems concepts.

Term Category Definition & Technical Context
CPython Runtime The standard, reference C-based implementation of the Python programming language that compiles Python source code into bytecode and executes it via a stack-based virtual machine.
PyObject Memory The foundational C struct in CPython from which all Python objects inherit, containing the reference count (ob_refcnt) and the object type pointer (ob_type).
Global Interpreter Lock (GIL) Concurrency A mutual-exclusion lock used by CPython to ensure only one OS thread executes Python bytecode at any given moment, preventing race conditions on memory reference counts.
Method Resolution Order (MRO) OOP The deterministic algorithmic order (computed via C3 Linearization) in which Python searches for method implementations across complex multiple inheritance class hierarchies.
Abstract Base Class (ABC) OOP A class defined via the abc module that enforces interface contracts by prohibiting instantiation of subclasses unless all @abstractmethod declarations are overridden.
Dunder Methods Data Model Special 'double underscore' methods (e.g. __init__, __getitem__, __call__) that bind user-defined classes into Python's built-in syntax, operators, and protocols.
Dynamic Array Over-Allocation Algorithms The growth strategy used by Python's list where extra capacity is pre-allocated proportionally during appends to achieve amortized O(1) insertion time.
Hash Table Perturbation Data Structures The collision resolution algorithm in CPython dicts that incorporates high-order bits of the hash code to break cyclic probing patterns in open addressing.
Call Stack Frame (PyFrameObject) Runtime The heap-allocated C struct representing a function execution scope, storing local variables, the evaluation value stack, instruction pointer, and globals dict.
Asyncio Event Loop Concurrency A single-threaded reactive scheduler that manages and dispatches asynchronous tasks and I/O callbacks via non-blocking OS multiplexers (epoll/kqueue).
Descriptor Protocol Metaprogramming An object attribute protocol implementing __get__, __set__, or __delete__, providing the underlying engine for properties, classmethods, and ORM fields.
Timsort Algorithms A hybrid adaptive sorting algorithm combining MergeSort and InsertionSort designed by Tim Peters, providing O(N) best-case and O(N log N) worst-case time complexity.
Context Manager Control Flow An object adhering to the runtime context protocol (__enter__ and __exit__) utilized within 'with' statements to guarantee deterministic resource cleanup.
Cyclomatic Complexity Software Eng A software metric indicating the number of linearly independent execution paths through source code, calculated as M = E - N + 2P.
SIMD Vectorization Performance Single Instruction Multiple Data: hardware CPU instructions utilized by NumPy to perform parallel arithmetic operations across contiguous memory buffers in C.
